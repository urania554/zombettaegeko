# Zombetta e Geko – sito

Sito statico de *Le avventure di Zombetta e Geko*, pubblicato con Netlify.

- Pagine: `index.html`, `libri.html`, `video.html`, `canzone.html`, `giochi.html`, `negozio.html`, `condizioni.html`, `privacy.html`, `grazie.html`
- Stile: `style.css` · Script: `site.js`, `giochi.js`
- Immagini in `img/`, font in `fonts/`
- Il modulo d'ordine del negozio usa Netlify Forms (gli ordini arrivano nella sezione Forms di Netlify e per email).
- `_genera_pagine.py` rigenera le pagine HTML (header e footer comuni, dati del negozio in `NEG`).
